# 股票分析日报展示平台

## 项目概述
开发一个简洁的金融科技风格 Web 应用，用于展示股票各模块的每日走势分析数据。

## 技术栈
- Next.js 14 App Router + TypeScript + Tailwind CSS
- 表格渲染：TanStack Table（react-table）或 shadcn/ui DataTable
- Excel 解析：SheetJS（xlsx）
- 日期处理：date-fns

---

## 核心功能

### 1. 文件上传
- 页面初始仅展示一个拖拽上传区域，支持拖拽或点击上传 Excel 文件（.xlsx/.xls）
- 上传后解析并展示表格数据

### 2. 数据预处理（上传后自动执行）
按以下顺序处理：

| 步骤 | 规则 |
|------|------|
| 清洗空数据 | 删除整行或整列为空的行列 |
| 日期格式化 | 第一行日期统一转为 `YYYY/MM/DD` 格式 |
| 逆序排列 | 日期从最新 → 最旧排列（原 Excel 是从旧到新） |
| 错行对齐 | 参照最近 7 天数据，将"近期有空白但远期有数据"的列移到表格末尾 |

#### 错行对齐详细规则
- 检查最近 7 天的每一列数据
- 如果某列在最新日期有数据，但近期（7天内）存在空白 → 保留原位
- 如果某列在最新日期无数据，但远期（7天外）有数据 → 将该列移至表格末尾区域
- 目的：确保用户打开页面第一眼看到的都是完整数据，避免横向滚动查找

### 3. 表格展示
- 第一行为日期行，固定表头（sticky header）
- 日期格式：`YYYY/MM/DD`
- 支持横向滚动（列数可能很多）
- 每个单元格的内容比较多，建议高度自适应，避免内容被截断
- 单元格内的加粗和字体样式要保留
- 金融科技风格：深色/浅色主题均可，要求简洁、专业、数据密度高


## UI 要求
- 页面初始仅显示拖拽上传区，上传后进入表格视图
- 金融科技风格：简洁、数据驱动、低饱和度配色、清晰的分隔线
- 表格紧凑，减少内边距，最大化信息密度
- 表头日期列可点击排序（但默认按新→旧）
- 响应式：移动端横向滚动流畅，表头固定

## 输出要求
1. 提供完整的 Next.js 页面组件（`app/page.tsx`）
2. 数据预处理逻辑封装为独立工具函数（`lib/processExcel.ts`）
3. 表格组件封装为可复用组件（`components/DataTable.tsx`）
4. 包含必要的类型定义（`types/excel.ts`）
5. 样式使用 Tailwind CSS，不使用 inline style
